Sau

Made a new basket on the request-baskets instance (v1.2.1). There’s a CVE for this version - a POST to a vulnerable endpoint makes the server itself request a locally running service. Useful, since port 80 is filtered externally in the nmap scan. Pointed it at the local mailtrail service, which has its own simple CVE providing a reverse shell. Privesc: sudo -l allowed systemctl, which pages output through less - escaped with !sh for a root shell.
